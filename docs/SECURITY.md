# Security Guide

## Included protections

- Spring Security with JWT authentication
- BCrypt password hashing
- Role-based access control
- Tenant-aware repository and service filtering
- Global exception handling and safe error responses
- Input validation and request size guardrails
- Audit logging for operational changes
- Sensitive data redaction for obvious patterns like email, phone, and card-like numbers

## Important note

This MVP is not a substitute for full regulatory compliance. Production environments may require explicit consent management, retention policies, encryption, regional storage controls, access review, and industry-specific compliance validation.
